## ✨ Features

* **Instant Scaffolding**: Automatically generate problem folders and C++ templates with metadata.
* **Standardized Structure**: Keeps your workspace organized and consistent.
* **Zero Footprint**: Install and uninstall cleanly without leaving junk in your system.
* **Intuitive Subcommands**: Familiar Git-like syntax (`new`, `rm`) for a smooth developer experience.
  
## 💻 Compatibility

AlgoFlow is a Bash-based CLI tool. It is designed to work on:
* **macOS**: Native support.
* **Linux**: Native support.
* **Windows**: Requires [WSL](https://learn.microsoft.com/en-us/windows/wsl/install) or [Git Bash](https://gitfor-windows.github.io/).

## 🚀 Quick Start
### install
```bash
curl -sSL https://raw.githubusercontent.com/xiechunyao/AlgoFlow/main/install.sh | bash
```
### uninstall
```bash
curl -sSL https://raw.githubusercontent.com/xiechunyao/AlgoFlow/main/uninstall.sh | bash
```
